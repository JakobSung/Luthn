This console is for operators. Start with access setup, then choose one workflow. Agents never receive approval or raw protected content.

  1. 01 Set up access

    Use Console access to connect one bounded Personal Local session. Enrolled installations require Cloud login.

  2. 02 Review a decision

    Select a pending sensitive-access request. Only allowlisted metadata and a redacted summary are shown.

  3. 03 Investigate the trail

    Use a preset to trace access, failures, configuration, publication, or retention metadata.

How this console authenticates

Starting secure session

The Host keeps the credential server-side. The browser receives only a bounded HttpOnly session cookie and never reads a service or decision token.

LocalAuto is available from this screen only for an un-enrolled SingleOwner installation bound to loopback. Cloud mode requires login.

01 Personal Local = one-time authorized session

No key entry is needed. The server permits it only on the hardened personal installation.

02 Luthn Cloud = login required

After enrollment, LocalAuto is revoked and human access is derived from Cloud membership.

03 Agent credentials stay separate

Existing service tokens continue to authenticate agents and API clients, never a human console session.
